A 4 KB Python chess engine: 0x88 board, negamax alpha-beta with iterative deepening under a fixed node budget, quiescence over captures and promotions, MVV-LVA move ordering, and a material plus centrality evaluation. It plays the make.fun tiny-chess-01 protocol over HTTP.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
